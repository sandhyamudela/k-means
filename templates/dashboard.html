Educational & Technical Viva Reference

What is K-Means Clustering?

K-Means is an unsupervised machine learning algorithm that partitions dataset points into K distinct, non-overlapping clusters based on Euclidean distance similarity to cluster centroids.

What is the Elbow Method?

The Elbow Method computes Within-Cluster Sum of Squares (WCSS / Inertia) across a range of K values (2 to 10). The optimal K is selected at the "elbow point" where adding more clusters yields diminishing returns.

Why Feature Scaling (StandardScaler)?

Distance-based algorithms like K-Means are sensitive to variable scales. Standardizing features to mean=0 and variance=1 prevents variables with larger ranges (e.g., Annual Income) from dominating distance calculations.
